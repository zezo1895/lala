🐙 المزامنة التلقائية مع GitHub (data.json)

أول ما تدوس حفظ، الموقع هيبعت كل بياناتك وفويساتك لملف data.json على الجيت هاب تلقائياً! يارا أول ما تفتح الموقع هيتحدث عندها مباشرة بدون ما تحتاج تبعتلها لينكات جديدة.

💡 إزاي تجيب توكن GitHub في دقيقة واحدة؟ (اضغط هنا)
  1. ادخل على إعدادات حسابك: GitHub Tokens
  2. اضغط على Generate new token واختار Generate new token (classic).
  3. اكتب في الملاحظة (Note) أي اسم مثل: yara-app.
  4. علّم علامة صح على مربع repo (عشان يقدر يكتب في data.json).
  5. انزل لآخر الصفحة واضغط Generate token.
  6. انسخ الكود اللي هيظهر (بيبدأ بـ ghp_...) وحطه في خانة التوكن بالأسفل واضغط حفظ. التوكن محفوظ في جهازك أنت بس ومستحيل يارا تشوفه.
